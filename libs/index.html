Information reviewed by the scanner

Old Guys PC Checker may collect and log the following from this Windows computer:

  • Current and historical process records, including process names, IDs, paths and available command-line details.
  • Browser download history from supported browser profiles.
  • Specified Windows registry entries and their stored values.
  • Kernel driver information, including active or inactive status where available.
  • Windows Defender records, including detections, status events and selected security settings.
  • Windows security and elevation events, timestamps and keyword matches.

The report may contain computer and account names, Windows version, uptime, file paths, download records, event details and other activity-related metadata. It is not a complete copy of your personal files.

Storage and transmission: the report is saved locally. If a Discord webhook is configured in Reports, the report may be sent to that webhook for staff review. Leave the webhook blank to keep the report local. A webhook is a secret and should only be supplied if you trust its recipient.

Remote access: sending a report does not give staff remote desktop access or the ability to browse your files through this application. Review the report destination before scanning.

02 / Module Required

Browser history
needs access.

Reading download records from Chrome, Edge, Firefox and other browsers requires a small PowerShell data-access module called PSSQLite.

Database readerOptional install
PSSQLite Module

Allow database reader?

To include browser download history in your report, the checker needs PSSQLite — an open-source PowerShell module for reading the local history files browsers use to store download records.

What is PSSQLite?

PSSQLite is a lightweight, open-source module published on the PowerShell Gallery. It provides read-only access to local browser history files — the format used by Chrome, Edge, Brave, Vivaldi, Firefox and others to store local history.

  • What it does: allows the checker to query browser History files and extract download records for the report.
  • What it does not do: it cannot write to any browser file, modify your files, or connect to the internet independently.
  • Where it installs: current user only, under your personal PowerShell modules folder. No admin required.
  • Already installed? If PSSQLite is already present on this machine the existing copy will be used and nothing is downloaded.
  • Declining: browser download history will be skipped and this application will close.
!
One-time install. PSSQLite is approximately 50 KB and installs silently in the background when the scan starts.

Transmission consentYour choice
Discord Webhook Consent

Send report via Discord?

Your report can be transmitted over HTTPS to the OldGuys Discord webhook for staff review. Selecting No keeps all scan details local — only a brief privacy summary is sent.

What each choice means

Yes — send full report: the complete system report is attached and uploaded to the OldGuys Discord webhook. Staff can review all collected records: processes, drivers, browser history, Defender events and flagged items.

No — local only: the full report is saved on this machine only. Discord receives a single line reading “Remote reporting declined” alongside your username, date and time, and a total count of flagged items — no details.

  • Encryption: all data is sent over HTTPS. Discord handles transport security.
  • No remote access: OldGuys staff receive the report file only. They cannot connect to or control this machine.
  • Local copy: the full report is always saved to this machine regardless of your choice here.
  • Flag count only: if you decline, only the number of flagged items is shared — not what they are.
!
Your data, your choice. A full report helps staff assist you faster. Declining keeps your scan private while still notifying staff that a scan took place.
Full report always saved locally regardless of choice.
